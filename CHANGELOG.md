# Changelog

## v2.0.0

- Replace the editor toolbar with a compact layout and explicit creation/filling modes.
- Group file actions under the current filename and editing actions under Edit; show existing shortcuts and implement Ctrl+A / Command+A for active-page field selection.
- Make Delete fields and Reset fields operate only on the selection; reset preserves field geometry and settings and remains undoable.
- Add continuous PDF reading, with a next-page loading button for documents longer than 20 pages.
- Add pointer-targeted table creation, a green preview and optional automatic table recognition.
- Replace center alignment with left, right and bottom edges, alongside table-cell alignment.
- Move PDF view controls to the footer; retain menu sizing and full language names at the top right.
- Preserve editable PDF saves, standalone fillable HTML forms, offline one-file delivery and legacy browser storage compatibility.
